# Personal Mini-Toolkit

A menu-driven command-line Python application that brings together three everyday utilities in one place: a **To-Do List Manager**, a **Simple Calculator**, and a **Number-Guessing Game**.

## How to Run
1. Make sure you have **Python 3** installed on your computer.
2. Clone or download this repository.
3. Open your terminal/command prompt in the project folder and run:
   ```bash
   python toolkit.py
